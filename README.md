# 📉 Global Layoffs Market Analysis

## 📌 Project Overview
A comprehensive exploratory data analysis of global corporate layoffs, focusing on standardizing messy data and tracking rolling job loss trends across industries, countries, and funding stages.

## 🛠️ Tools & Technologies
* **MySQL:** Relational database management.
* **Advanced SQL:** Common Table Expressions (CTEs), Window Functions (`DENSE_RANK`, `PARTITION BY`), and aggregate filtering.

## ⚙️ Methodology & Data Cleaning
* Resolved raw data inconsistencies including duplicate records, null values, and unstandardized date formats.
* Engineered queries to calculate rolling totals of layoffs over time using window functions.

## 📊 Key Business Insights
* Analyzed and ranked the hardest-hit industries and geographic locations over a multi-year period.
* Correlated layoff volume with company funding stages to identify market vulnerabilities.
